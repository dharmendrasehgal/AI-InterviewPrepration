## Epic 1: User & Account Management
_Parent: BR-01, BR-01.1 – BR-01.5_

---

### US-01: Candidate Registration
**As a** job seeker,  
**I want to** create an account using my email or Google account,  
**so that** I can access the platform's practice tools.

**Acceptance Criteria:**
- [ ] AC-01.1: Registration form accepts email, password, full name, and role selection (Candidate/Expert).
- [ ] AC-01.2: Google OAuth login completes registration in a single click without a password.
- [ ] AC-01.3: A verification email is sent within 60 seconds of registration.
- [ ] AC-01.4: Unverified accounts cannot access practice tools — a banner prompts email verification.
- [ ] AC-01.5: Duplicate email registration shows a clear error: "An account with this email already exists."

---

### US-02: Candidate Profile Setup
**As a** candidate,  
**I want to** upload my resume and set my target role,  
**so that** the platform can personalize my practice questions.

**Acceptance Criteria:**
- [ ] AC-02.1: Candidate can upload PDF or DOCX files up to 5MB.
- [ ] AC-02.2: System parses and displays extracted name, current role, and top 5 skills within 10 seconds of upload.
- [ ] AC-02.3: Candidate can select target industry, career level (entry/mid/senior), and interview track.
- [ ] AC-02.4: AI mock questions reflect the selected track and target role within the next session.
- [ ] AC-02.5: Candidate can update or replace their resume at any time.

---

### US-03: Candidate Dashboard
**As a** candidate,  
**I want to** view my preparation progress on a dashboard,  
**so that** I can track improvement and plan my next steps.

**Acceptance Criteria:**
- [ ] AC-03.1: Dashboard shows total sessions completed (AI + human-led).
- [ ] AC-03.2: Dashboard shows average AI score across all sessions.
- [ ] AC-03.3: A trend graph displays score improvement over the last 10 sessions.
- [ ] AC-03.4: Dashboard shows upcoming booked sessions with date, time, and expert name.
- [ ] AC-03.5: Dashboard shows a "Resume Practice" button linking to the last incomplete or recent session.

---

### US-04: Expert Profile & Onboarding
**As an** expert/mentor,  
**I want to** submit my profile for review,  
**so that** I can offer live mock interview sessions to candidates.

**Acceptance Criteria:**
- [ ] AC-04.1: Expert can fill in bio, specialties (multi-select), years of experience, and LinkedIn URL.
- [ ] AC-04.2: Profile is submitted in "Pending Review" status and is not visible in the marketplace.
- [ ] AC-04.3: Expert receives an email notification when their profile is approved or rejected.
- [ ] AC-04.4: Admin receives an in-app alert when a new expert profile is pending review.
- [ ] AC-04.5: Admin can approve, reject with reason, or request more information.

## Epic 2: Content & Resource Library
_Parent: BR-02, BR-02.1 – BR-02.5_

---

### US-05: Browse & Filter Question Bank
**As a** candidate,  
**I want to** browse the question bank with filters,  
**so that** I can find relevant practice questions for my target role.

**Acceptance Criteria:**
- [ ] AC-05.1: Questions are displayed in a paginated list (25 per page).
- [ ] AC-05.2: Filters available: Type (Behavioral/Technical/Situational/Role-Specific), Industry, Career Level, Topic tag.
- [ ] AC-05.3: Multiple filters can be applied simultaneously.
- [ ] AC-05.4: Active filters are displayed as removable chips.
- [ ] AC-05.5: Filter results update within 500ms without a full page reload.

---

### US-06: Search Content Library
**As a** candidate,  
**I want to** search across all content,  
**so that** I can quickly find questions or articles on a specific topic.

**Acceptance Criteria:**
- [ ] AC-06.1: Search bar is visible on all content pages.
- [ ] AC-06.2: Autocomplete suggestions appear after 2 characters, showing up to 5 options.
- [ ] AC-06.3: Search returns results from questions, playbooks, and article titles.
- [ ] AC-06.4: Results are grouped by content type (Questions / Playbooks / Articles).
- [ ] AC-06.5: "No results found" state is shown with suggested alternative search terms.

---

### US-07: View Expert-Vetted Sample Answers
**As a** candidate,  
**I want to** see expert sample answers with guidance for each question,  
**so that** I can understand what a strong response looks like.

**Acceptance Criteria:**
- [ ] AC-07.1: Each question page includes at least one sample answer.
- [ ] AC-07.2: Sample answers display the recommended framework (e.g., STAR method label).
- [ ] AC-07.3: Sample answers are hidden behind a "Show Answer" toggle — candidates see the question first.
- [ ] AC-07.4: Candidates can bookmark a question from the question detail page.
- [ ] AC-07.5: Bookmarked questions appear in a "My Practice List" section on the dashboard.

---

### US-08: Access Industry Playbook
**As a** candidate,  
**I want to** access a playbook for my industry track,  
**so that** I have a structured preparation roadmap.

**Acceptance Criteria:**
- [ ] AC-08.1: At least 3 playbooks are available at launch: General Career, Software Engineering, Medical/Residency.
- [ ] AC-08.2: Each playbook includes an overview, curated question list, and preparation timeline.
- [ ] AC-08.3: Playbooks link to related video tutorials and articles.
- [ ] AC-08.4: Candidate's selected interview track auto-highlights the relevant playbook on the content home page.

## Epic 3: Interactive Practice Tools
_Parent: BR-03, BR-03.1 – BR-03.6_

---

### US-09: Start an AI Mock Interview
**As a** candidate,  
**I want to** start an on-demand AI mock interview,  
**so that** I can practice answering interview questions and get instant feedback.

**Acceptance Criteria:**
- [ ] AC-09.1: "Start AI Mock Interview" button is accessible from the dashboard.
- [ ] AC-09.2: A consent dialog is shown before the session starts; the session only begins after explicit acceptance.
- [ ] AC-09.3: The system checks camera and microphone permissions and shows a diagnostic if access is denied.
- [ ] AC-09.4: The AI presents 3–10 adaptive questions based on the candidate's profile and prior performance.
- [ ] AC-09.5: Each question is shown as text; the candidate has a configurable response window (default 2 minutes).
- [ ] AC-09.6: The session is recorded (audio + video) and uploaded upon completion.
- [ ] AC-09.7: AI score report is displayed within 60 seconds of session end.

---

### US-10: View AI Score Report
**As a** candidate,  
**I want to** see a detailed AI score report after my mock session,  
**so that** I know exactly where to improve.

**Acceptance Criteria:**
- [ ] AC-10.1: Report shows per-question scores: speech rate, filler word count, keyword relevance.
- [ ] AC-10.2: Report shows a session-level composite Clarity Score (0–100).
- [ ] AC-10.3: Each metric includes a plain-language improvement tip.
- [ ] AC-10.4: Report is accessible from the Feedback Archive after the session ends.
- [ ] AC-10.5: Candidate can replay the session recording inline within the report view.

---

### US-11: Book a Live Mock Interview Session
**As a** candidate,  
**I want to** book a 1-on-1 session with a verified expert,  
**so that** I can get human feedback on my interview performance.

**Acceptance Criteria:**
- [ ] AC-11.1: Expert marketplace shows approved experts with name, specialties, and available slots.
- [ ] AC-11.2: Candidate can view an expert's available time slots in a calendar view.
- [ ] AC-11.3: Candidate can book a slot; the slot is immediately blocked from other bookings.
- [ ] AC-11.4: Candidate receives email confirmation within 2 minutes of booking.
- [ ] AC-11.5: Expert receives email notification of the new booking within 2 minutes.
- [ ] AC-11.6: Reminder emails are sent 24 hours and 1 hour before the session to both parties.

---

### US-12: Join Live Session via Browser
**As a** candidate or expert,  
**I want to** join a live session in my browser without installing software,  
**so that** the session experience is seamless.

**Acceptance Criteria:**
- [ ] AC-12.1: A "Join Session" button activates within 10 minutes of session start time.
- [ ] AC-12.2: Consent dialog is shown before video/audio is activated; both parties must accept.
- [ ] AC-12.3: Video call connects via WebRTC within 10 seconds of both parties joining.
- [ ] AC-12.4: If WebRTC fails, the system displays a fallback option (Zoom link, if configured).
- [ ] AC-12.5: Session recording begins only after both consent dialogs are accepted.

---

### US-13: Self-Practice Record & Review
**As a** candidate,  
**I want to** record myself answering a question and review my response,  
**so that** I can independently assess my pacing and tone without needing an expert.

**Acceptance Criteria:**
- [ ] AC-13.1: Candidate can start a self-practice recording from any question page.
- [ ] AC-13.2: Recording controls include: Start, Pause, Resume, Stop.
- [ ] AC-13.3: Playback shows waveform visualization and a words-per-minute pacing overlay in 10-second intervals.
- [ ] AC-13.4: Self-practice recordings are marked as private — not shared with experts or Admins.
- [ ] AC-13.5: Candidate can delete any self-practice recording permanently.

## Epic 4: Evaluation & Feedback
_Parent: BR-04, BR-04.1 – BR-04.5_

---

### US-14: Expert Submits Rubric Evaluation
**As an** expert,  
**I want to** complete a structured evaluation form after a live session,  
**so that** the candidate receives structured, actionable feedback.

**Acceptance Criteria:**
- [ ] AC-14.1: After a live session ends, the expert sees a "Complete Evaluation" prompt in their dashboard.
- [ ] AC-14.2: Rubric form includes 4 scored categories (1–5 stars): Communication, Competence, Confidence, Preparation.
- [ ] AC-14.3: Each category includes a free-text comment field.
- [ ] AC-14.4: Expert can add an overall summary comment.
- [ ] AC-14.5: Submitting the rubric triggers a notification to the candidate.
- [ ] AC-14.6: Submitted rubrics cannot be edited after submission.

---

### US-15: Review Feedback Archive
**As a** candidate,  
**I want to** access all my past session recordings and feedback in one place,  
**so that** I can track improvement and reference past guidance.

**Acceptance Criteria:**
- [ ] AC-15.1: Feedback Archive lists all past sessions (AI + human-led) in reverse chronological order.
- [ ] AC-15.2: Each entry shows: date, session type, expert name (if applicable), AI score (if applicable), rubric summary (if applicable).
- [ ] AC-15.3: Candidate can filter archive by session type, date range, and score range.
- [ ] AC-15.4: A progress trend chart displays composite scores over time.
- [ ] AC-15.5: Candidate can replay any session recording inline.
- [ ] AC-15.6: Candidate can download their session transcript as a PDF.
