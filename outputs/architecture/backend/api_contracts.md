## Module: Auth (`/auth`)

| Method | Endpoint | Auth | Description |
|--------|----------|------|-------------|
| POST | `/auth/register` | Public | Register with email + password |
| POST | `/auth/login` | Public | Login, returns access + refresh tokens |
| POST | `/auth/logout` | Required | Invalidate refresh token |
| POST | `/auth/refresh` | Cookie | Exchange refresh token for new access token |
| POST | `/auth/verify-email` | Public | Confirm email with token from link |
| POST | `/auth/forgot-password` | Public | Request password reset email |
| POST | `/auth/reset-password` | Public | Reset password with token |
| GET | `/auth/oauth/google` | Public | Redirect to Google OAuth |
| GET | `/auth/oauth/google/callback` | Public | Google OAuth callback |

**POST `/auth/register` — Request:**
```json
{
  "email": "candidate@example.com",
  "password": "MinLength8!",
  "full_name": "Jane Smith",
  "role": "candidate"
}
```
**Response 201:**
```json
{
  "data": { "user_id": "usr_01", "email": "...", "role": "candidate" },
  "meta": { "message": "Verification email sent" }
}
```

**POST `/auth/login` — Response 200:**
```json
{
  "data": {
    "access_token": "eyJ...",
    "expires_in": 900,
    "user": { "user_id": "usr_01", "role": "candidate", "email_verified": true }
  }
}
```
Refresh token set as `HttpOnly; SameSite=Strict` cookie.
