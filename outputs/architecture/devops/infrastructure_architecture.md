## 2. ECS Service Definitions

### API Service (REST)
```hcl
# terraform/modules/ecs/api-service.tf
resource "aws_ecs_service" "api" {
  name            = "interview-prep-api"
  cluster         = aws_ecs_cluster.main.id
  task_definition = aws_ecs_task_definition.api.arn
  desired_count   = 2
  launch_type     = "FARGATE"

  network_configuration {
    subnets          = var.private_subnet_ids
    security_groups  = [aws_security_group.api.id]
    assign_public_ip = false
  }

  load_balancer {
    target_group_arn = aws_lb_target_group.api.arn
    container_name   = "api"
    container_port   = 3001
  }
}

# Task: 0.5 vCPU, 1GB RAM per task (2 tasks = 1 vCPU, 2GB baseline)
# Auto-scale: 2–20 tasks based on CPU > 70% (5-min average)
```

### Worker Service (BullMQ)
```hcl
resource "aws_ecs_service" "worker" {
  name          = "interview-prep-worker"
  desired_count = 4
  # 0.5 vCPU, 1GB RAM per worker task
  # Scale: queue depth > 20 per worker → add task
  # No load balancer — workers pull from Redis queue
}
```

### Whisper STT (EC2, not Fargate)
```hcl
resource "aws_instance" "whisper" {
  ami           = "ami-deep-learning-ubuntu"  # AWS Deep Learning AMI
  instance_type = "g4dn.xlarge"              # 1× NVIDIA T4, 4 vCPU, 16GB RAM
  subnet_id     = var.gpu_subnet_id

  # Whisper large-v3 model loaded at startup
  # Exposes HTTP endpoint: POST /transcribe (audio file → transcript JSON)
  # Health check: GET /health
  # Monitored: if health check fails > 2 min → alert + route new jobs to Google STT fallback
}
```

## 4. Security Groups

| Security Group | Inbound | Outbound |
|---------------|---------|----------|
| `sg-alb` | 443 from 0.0.0.0/0; 3478 UDP from 0.0.0.0/0 | All to `sg-api` |
| `sg-api` | 3001 from `sg-alb`; 3002 from `sg-alb` | All to `sg-data`; HTTPS to internet (via NAT) |
| `sg-signaling` | 3003 from `sg-alb` | All to `sg-data`; UDP to `sg-coturn` |
| `sg-data` | 5432 from `sg-api`; 6379 from `sg-api`, `sg-worker`, `sg-signaling` | None |
| `sg-gpu` | 8080 from `sg-worker` | HTTPS to internet (Anthropic fallback) |
| `sg-coturn` | 3478 UDP from 0.0.0.0/0 | All |

## 6. Disaster Recovery

| Tier | RTO | RPO | Strategy |
|------|-----|-----|---------|
| RDS (Primary DB) | ≤ 4h | ≤ 1h | Multi-AZ automatic failover; daily automated snapshots (7-day retention); point-in-time recovery enabled |
| Redis (ElastiCache) | ≤ 15min | 0 (replication) | Cluster mode with 1 replica per shard; auto-failover enabled |
| S3 (Recordings) | Immediate | 0 | Cross-region replication to us-west-2 for recordings bucket; versioning OFF (cost), replication ON |
| ECS Services | ≤ 5min | N/A (stateless) | Multi-AZ Fargate tasks; ALB health checks trigger replacement; blue-green deployment |
| Whisper GPU | ≤ 30min | N/A | AMI snapshot weekly; fallback to Google STT API if instance unavailable > 2min |

**Backup Testing:** Monthly automated restore test from RDS snapshot to isolated VPC (automated via Lambda).
