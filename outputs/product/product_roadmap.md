## Phase 1 — MVP (Q3 2026, ~12 weeks)

**Theme:** Build the core AI-driven preparation loop — register, practice, get scored, improve.

**Goal:** Allow a candidate to sign up, configure their profile, run an AI mock interview, and receive actionable feedback, all within 10 minutes of first visit.

### Features Included

| Priority | Feature | User Stories | Effort |
|----------|---------|-------------|--------|
| P0 | User Registration & Authentication (Candidate + Admin roles) | US-01 | M |
| P0 | Candidate Profile Setup (resume upload + target role) | US-02 | M |
| P0 | Candidate Dashboard | US-03 | S |
| P0 | Question Bank — Behavioral & Technical (≥200 questions at launch) | US-05, US-07 | L |
| P0 | Full-Text Search & Filters | US-06 | M |
| P0 | AI Mock Interview Session (on-demand, adaptive) | US-09 | XL |
| P0 | AI Score Report (speech rate, filler words, keyword relevance) | US-10 | L |
| P0 | Feedback Archive (AI sessions only) | US-15 | M |
| P1 | Admin Dashboard (user management + question bank management) | FR-04 | M |
| P1 | Email Notifications (registration, session complete) | FR-12 | S |

### Phase 1 Exit Criteria
- [ ] A candidate can register, complete profile setup, and start an AI mock session in < 10 minutes.
- [ ] AI score report is delivered within 60 seconds of session completion.
- [ ] Question bank contains ≥ 200 questions across Behavioral and Technical categories.
- [ ] Platform passes WCAG 2.1 AA audit on all Phase 1 screens.
- [ ] All PII is encrypted at rest and in transit (verified by security review).

## Phase 2 — Growth (Q4 2026, ~10 weeks)

**Theme:** Activate the human mentorship loop — connect candidates with verified experts for live practice.

**Goal:** Enable expert marketplace with bookable live sessions and expand content library with playbooks and self-practice tools.

### Features Included

| Priority | Feature | User Stories | Effort |
|----------|---------|-------------|--------|
| P0 | Expert Registration & Admin Approval Workflow | US-04 | M |
| P0 | Expert Marketplace (browse + filter verified experts) | US-11 | M |
| P0 | Session Booking System (availability calendar, confirmations) | US-11, US-12 | L |
| P0 | Live Mock Interview via WebRTC (consent, recording, archive) | US-12 | XL |
| P0 | Expert Rubric Evaluation Form | US-14 | M |
| P0 | Session Reminders & Cancellation Notifications | FR-12 | S |
| P1 | Industry Playbooks — General Career, Software Engineering, Medical/Residency | US-08 | L |
| P1 | Self-Practice Record & Review Tool | US-13 | M |
| P1 | Feedback Archive — Human sessions + rubric scores | US-15 | S |
| P1 | Progress Trend Chart (score improvement over time) | US-03, US-15 | S |
| P2 | Video Tutorials & Articles Content Hub | FR-08 | M |

### Phase 2 Exit Criteria
- [ ] At least 50 verified experts are live in the marketplace at Phase 2 launch.
- [ ] Booking-to-session success rate ≥ 90% (no double-bookings, broken links).
- [ ] WebRTC sessions connect successfully on Chrome, Firefox, and Edge.
- [ ] Rubric evaluation form completion rate by experts ≥ 80% within 24h of session.
