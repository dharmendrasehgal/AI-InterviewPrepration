## Release Gates

Each release must pass all gate criteria before proceeding. No exceptions without explicit Product Owner sign-off.

---

## Release 0: Alpha (End of Sprint 4 — Week 8)

**Audience:** Internal team + 5–10 invited testers only  
**Purpose:** Validate the core AI mock interview loop end-to-end before broader exposure

### Included Features
- User registration and login (email + Google OAuth)
- Candidate profile setup (resume upload + target role)
- Question Bank browsing and search (≥ 100 questions)
- AI Mock Interview session (recording + STT)
- Basic AI score report (raw metrics only, no tips yet)

### Alpha Gate Criteria
- [ ] No P0 bugs in the candidate registration → AI session → score report journey
- [ ] STT transcription accuracy ≥ 80% on clear English speech (measured internally)
- [ ] Recording upload completes successfully for sessions up to 30 minutes
- [ ] All forms are keyboard-navigable
- [ ] No PII is logged in application logs (verified by security review)

### Alpha Risks
| Risk | Mitigation |
|------|-----------|
| STT API provider not finalized (OQ-15) | Use Whisper as interim default; swap to selected provider before Beta |
| AI question selection not adaptive yet | Use rule-based selection by track for Alpha |

## Release 1: Closed Beta (End of Sprint 5 — Week 10)

**Audience:** 100–500 invited candidates (diverse roles: software engineers, general job seekers)  
**Purpose:** Validate end-to-end UX quality, score report usefulness, and retention behavior

### Included Features (cumulative)
- All Alpha features
- Full AI Score Report with per-question breakdown and improvement tips
- Feedback Archive with session replay
- Candidate Dashboard with live metrics and trend graph
- Bookmarking questions
- Email notifications (registration verification, score ready)
- Admin user management panel

### Closed Beta Gate Criteria
- [ ] AI score report delivered within 60 seconds for 95% of sessions
- [ ] Candidate dashboard loads in ≤ 2 seconds (measured via Lighthouse on prod)
- [ ] Zero critical security vulnerabilities in automated scan
- [ ] WCAG 2.1 AA: 0 critical failures (verified with axe-core)
- [ ] ≥ 70% of Beta candidates complete at least 1 AI session within 48 hours of registration
- [ ] NPS from Beta candidates ≥ 30

### Beta Feedback Channels
- In-app feedback widget (thumbs up/down + text comment after each session)
- Bi-weekly user interviews (5 candidates per week)
- Automated error reporting (Sentry or equivalent)

## Release 2: General Availability — Phase 1 (End of Sprint 6 — Week 12)

**Audience:** Public launch — all job seekers  
**Purpose:** Full Phase 1 MVP is available to the public

### Included Features (cumulative)
- All Beta features
- Search autocomplete
- Session transcript PDF download
- GDPR/CCPA privacy controls (consent banner, data deletion request)
- Full WCAG 2.1 AA compliance
- Security hardening complete (rate limiting, CSP, HSTS)
- Structured logging and uptime alerting live

### GA Gate Criteria (Go/No-Go Checklist)
- [ ] All Sprint 6 tasks completed and verified
- [ ] Zero P0 bugs open
- [ ] External penetration test completed; all critical findings remediated
- [ ] Privacy policy and cookie consent live and legally reviewed
- [ ] Load test passed: 500 concurrent AI sessions with p95 latency ≤ 3s
- [ ] Uptime alerting configured and tested (on-call rotation confirmed)
- [ ] ≥ 200 questions in the Question Bank across Behavioral and Technical categories
- [ ] Support/help channel active (email support minimum)

### GA Launch Checklist
- [ ] Redirect www domain to production environment
- [ ] CDN configured for static assets
- [ ] Database backups verified and automated (daily)
- [ ] Status page live (e.g., status.platform.com)
- [ ] Launch announcement prepared (blog post, LinkedIn, email to Beta waitlist)

## Release 3: Phase 2 Launch (Q4 2026)

**Audience:** Candidates + Expert/Mentor cohort  
**Purpose:** Activate the human mentorship marketplace

### Included Features
- Expert registration, profile, and admin approval workflow
- Expert marketplace (browse, filter, book)
- Live mock interview via WebRTC (with consent, recording, archive)
- Expert rubric evaluation form
- Booking confirmation, reminders, cancellation notifications
- Industry Playbooks (3 tracks)
- Self-Practice Record & Review

### Phase 2 Pre-Launch Requirements
- [ ] ≥ 50 verified experts onboarded and available for booking
- [ ] WebRTC tested successfully on Chrome, Firefox, and Edge
- [ ] Booking flow load-tested for 100 concurrent sessions
- [ ] Expert compensation model finalized (pending OQ-09)
- [ ] Legal: recording consent flow reviewed by counsel
