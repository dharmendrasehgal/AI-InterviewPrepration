## Sprint Cadence

- Sprint duration: 2 weeks
- Sprint start: Week 1 of Q3 2026
- Definition of Done: Feature is implemented, unit-tested, reviewed, and accessible (WCAG checked).

---

## Sprint 1 — Foundation (Weeks 1–2)

**Goal:** Authentication, roles, and data schema in place so all subsequent sprints can build on a stable base.

| ID | Task | Priority | Dependency |
|----|------|----------|------------|
| S1-01 | Set up project repository, CI/CD pipeline, and cloud infrastructure (staging + prod environments) | P0 | None |
| S1-02 | Database schema design: Users, Roles, Sessions, Questions, Answers, Scores, Bookmarks | P0 | None |
| S1-03 | Implement authentication: email/password registration + Google OAuth | P0 | S1-01, S1-02 |
| S1-04 | Role-based access control middleware (Candidate / Expert / Admin) | P0 | S1-03 |
| S1-05 | Email verification flow (send verification link, confirm endpoint) | P0 | S1-03 |
| S1-06 | Password reset flow (request, token validation, reset) | P1 | S1-03 |
| S1-07 | Basic responsive layout shell (navigation, header, footer) | P1 | S1-01 |

**Sprint 1 Exit:** A user can register, verify their email, log in, and be redirected to a role-appropriate landing page.

## Sprint 3 — Question Bank (Weeks 5–6)

**Goal:** Question bank is live with ≥ 200 questions, fully filterable and searchable.

| ID | Task | Priority | Dependency |
|----|------|----------|------------|
| S3-01 | Question Bank data model: type, industry, career level, tags, sample answers | P0 | S1-02 |
| S3-02 | Admin: Create, edit, publish, archive questions and sample answers | P0 | S2-05 |
| S3-03 | Question browsing UI: paginated list (25/page) with multi-faceted filters | P0 | S3-01 |
| S3-04 | Question detail page: question text, difficulty, sample answer (collapsed by default) | P0 | S3-01 |
| S3-05 | Bookmarking: candidate can bookmark questions; bookmarks appear in dashboard | P1 | S3-03 |
| S3-06 | Full-text search: search bar with results grouped by type | P0 | S3-01 |
| S3-07 | Search autocomplete: suggestions after 2 characters (up to 5 options) | P1 | S3-06 |
| S3-08 | Seed database with ≥ 200 curated questions (Behavioral + Technical) | P0 | S3-02 |

**Sprint 3 Exit:** Question bank live with ≥ 200 questions; search and filters functional; admin can manage content.

## Sprint 4 — AI Mock Interview Engine (Weeks 7–8)

**Goal:** Candidates can run a complete AI mock interview session end-to-end.

| ID | Task | Priority | Dependency |
|----|------|----------|------------|
| S4-01 | Integrate Speech-to-Text API (Google STT or Whisper — pending OQ-15) | P0 | S1-01 |
| S4-02 | Integrate AI provider for adaptive question selection (pending OQ-14) | P0 | S1-01 |
| S4-03 | Session recording: browser-based webcam + microphone capture via MediaRecorder API | P0 | S1-07 |
| S4-04 | Recording consent dialog: block session start until explicit acceptance; log consent event | P0 | S4-03 |
| S4-05 | AI Mock Interview session UI: question display, timer, record controls | P0 | S4-03 |
| S4-06 | Session completion: upload recording to secure cloud storage; trigger STT transcription | P0 | S4-01, S4-03 |
| S4-07 | Adaptive question selection logic: use candidate profile + past session data to pick questions | P1 | S4-02, S3-01 |
| S4-08 | Question response time configuration (30s – 5 min; default 2 min) | P1 | S4-05 |

**Sprint 4 Exit:** Candidate can start, complete, and submit an AI mock session. Recording is stored and transcription job is queued.

## Sprint 5 — AI Scoring & Feedback Archive (Weeks 9–10)

**Goal:** AI score report is generated and accessible; Feedback Archive is functional.

| ID | Task | Priority | Dependency |
|----|------|----------|------------|
| S5-01 | AI Scoring Engine: speech rate (WPM) calculation from transcript | P0 | S4-01 |
| S5-02 | AI Scoring Engine: filler word detection ("um", "uh", "like", "you know") | P0 | S4-01 |
| S5-03 | AI Scoring Engine: keyword relevance scoring against expected answer criteria | P0 | S4-02 |
| S5-04 | Composite Clarity Score (0–100) aggregation from above metrics | P0 | S5-01, S5-02, S5-03 |
| S5-05 | AI Score Report UI: per-question scores + session summary + improvement tips | P0 | S5-04 |
| S5-06 | Score report available within 60 seconds of session end (async pipeline) | P0 | S5-05 |
| S5-07 | Feedback Archive: list all sessions in reverse chronological order | P0 | S4-06 |
| S5-08 | Feedback Archive: filter by date range and score range | P1 | S5-07 |
| S5-09 | Inline session replay in score report and archive | P0 | S4-06 |
| S5-10 | Session transcript PDF download | P2 | S4-01 |
| S5-11 | Candidate Dashboard — live data: sessions completed, average score, trend graph | P0 | S5-04 |

**Sprint 5 Exit:** Full AI mock interview loop is complete — session → transcription → scoring → report → archive.

## Sprint 6 — Hardening, Accessibility & Launch Prep (Weeks 11–12)

**Goal:** Platform is production-ready, secure, accessible, and performant for public launch.

| ID | Task | Priority | Dependency |
|----|------|----------|------------|
| S6-01 | Full WCAG 2.1 AA audit and remediation (keyboard nav, ARIA, contrast, captions) | P0 | All sprints |
| S6-02 | Security hardening: rate limiting, HSTS headers, CSP, input validation audit | P0 | All sprints |
| S6-03 | GDPR/CCPA: Privacy policy page, cookie consent banner, data retention cron job | P0 | S4-06 |
| S6-04 | Performance: achieve ≤ 2s TTI on content pages; lazy-load images and videos | P0 | All sprints |
| S6-05 | End-to-end testing: full candidate journey (register → profile → AI session → report → archive) | P0 | All sprints |
| S6-06 | Email notification templates: registration, session complete, score ready | P0 | S1-03, S5-06 |
| S6-07 | Error states: all critical flows have user-friendly error messages with next actions | P0 | All sprints |
| S6-08 | Observability: structured logging, metrics dashboard, uptime alerting configured | P1 | All sprints |
| S6-09 | Load test: simulate 500 concurrent AI sessions; validate auto-scaling behavior | P1 | S4-06 |
| S6-10 | Penetration test (external) or security scan | P0 | S6-02 |

**Sprint 6 Exit:** All Phase 1 exit criteria from roadmap are met. Launch go/no-go review passed.
