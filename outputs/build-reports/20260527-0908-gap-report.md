## Error Details

### ERR-001 — Wrong build context: project root has no Node.js source
- **Type:** BUILD-BC
- **Severity:** P0 — Blocker
- **Raw error:**
  ```
  => [api internal] load build context
  => => transferring context: 2B          ← only 2 bytes: context is effectively empty
  ERROR [api builder 3/6] COPY package.json package-lock.json tsconfig.json ./
  failed to compute cache key: "/package.json": not found
  ```
- **Root cause:** `docker-compose.yml` sets `context: ../../..` which resolves to the project root (`AI-InterviewPrepration/`). That directory contains only Markdown/HTML files — no `package.json`, `src/`, or `tsconfig.json`.
- **Affected file:** `outputs/implementation/devops/docker-compose.yml` — `api.build.context` and `worker.build.context`
- **Fix applied:** Changed both service build contexts from `../../..` to `../backend`. Updated Dockerfile COPY commands to match the actual directory layout (`modules/` not `src/`).
- **Owner:** `devops_agent` + `backend_dev_agent`
- **Status:** Fixed

### ERR-003 — Unset CLAUDE_API_KEY
- **Type:** BUILD-ENV
- **Severity:** P1 — High
- **Raw error:**
  ```
  WARN[0000] The "CLAUDE_API_KEY" variable is not set. Defaulting to a blank string.
  ```
- **Root cause:** `docker-compose.yml` references `${CLAUDE_API_KEY}` but no `.env` file exists in the working directory, so Docker Compose defaults to an empty string. Any Anthropic API call will fail at runtime with a 401.
- **Affected file:** `outputs/implementation/devops/docker-compose.yml` — `api.environment.CLAUDE_API_KEY` and `worker.environment.CLAUDE_API_KEY`
- **Fix applied:** Created `outputs/implementation/devops/.env.example` documenting all required variables. Users must copy to `.env` and supply a real key.
- **Owner:** `devops_agent`
- **Status:** Fixed (documentation); user action required — see `.env.example`

### ERR-007 — Missing jwt_private_key.pem
- **Type:** BUILD-MF
- **Severity:** P1 — High
- **Raw error:** `api` service mounts `./jwt_private_key.pem:/run/secrets/jwt_private_key:ro`. If the file does not exist, Docker creates a directory in its place, which breaks the secret read at runtime.
- **Root cause:** RSA private key for JWT RS256 signing must be generated locally — it cannot be committed to source control.
- **Fix applied:** Documented in `.env.example`. Users must run:
  ```bash
  openssl genrsa -out outputs/implementation/devops/jwt_private_key.pem 2048
  ```
- **Owner:** `devops_agent`
- **Status:** User action required — see `.env.example`

---

### ERR-008 — Obsolete `version` attribute in docker-compose.yml
- **Type:** BUILD-OBS
- **Severity:** P3 — Low
- **Raw error:**
  ```
  WARN[0000] docker-compose.yml: the attribute `version` is obsolete, it will be ignored
  ```
- **Root cause:** Docker Compose v2+ (the `docker compose` plugin) ignores the top-level `version:` key. It is a warning-only, no functional impact, but indicates outdated schema.
- **Fix applied:** Removed `version: '3.9'` from `docker-compose.yml`.
- **Owner:** `devops_agent`
- **Status:** Fixed
